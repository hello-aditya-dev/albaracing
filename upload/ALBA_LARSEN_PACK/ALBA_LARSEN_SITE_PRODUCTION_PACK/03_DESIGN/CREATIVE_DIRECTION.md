# Creative Direction

## Core idea

Working concept name: `NO SINGLE LANE`

Internal design principle: `EDITORIAL VELOCITY`

Do not present `NO SINGLE LANE` as an Alba-approved slogan. It is a design lens.

The site should feel like the meeting point of:
- an elite athlete's official home
- a modern fashion editorial
- motorsport broadcast restraint
- a youth brand system
- an unusually clean personal archive

## Key rule

Do not redesign Alba. Athletics already built a distinct Alba Racing identity. Digitally extend it.

## Visual duality without splitting her identity

Racing sections:
- tighter grid
- more mono data
- faster cuts
- more red / ink
- cropped action photography

World sections:
- larger margins
- paper/cream fields
- editorial serif
- slower image transitions
- fashion photography and objects

Performance:
- scientific restraint
- controlled graph language
- no fake health data

G.I.R.L.:
- human, participatory, community-first
- less hero worship
- groups and first-time experiences

## Avoid

- generic black/neon F1 template
- carbon fibre texture
- speedometer UI
- fake live telemetry
- mouse-following car
- constant 3D
- giant Ferrari branding dominating Alba
- pink "women in motorsport" clichés
- AI-generated pseudo-sponsor logos
- invented quotes
- fake magazine covers
- copy that claims endorsement
